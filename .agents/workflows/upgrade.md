# Workflow: Analyse et Amélioration (Global)

**Déclencheur** : Commande `/amélioration`

**Étapes** :
1.  Analyse la structure complète et le code du projet actuel.
2.  Identifie les points faibles : complexité inutile, dette technique, incohérences d'architecture.
3.  Propose une liste structurée de corrections et d'améliorations concrètes en français.
4.  Explique pour chaque point le gain attendu (performance, maintenance).
